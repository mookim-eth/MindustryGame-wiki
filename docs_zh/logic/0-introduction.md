# 介绍

**欢迎阅读官方但尚不完整的 Mindustry 逻辑手册。**

本文既是 Mindustry 逻辑的指南，也是参考资料。它包含与这门语言相关的基础和进阶信息。本手册旨在覆盖所有编程水平的读者，我们也在努力让完全不了解代码的人也能理解它。

## 什么是 Mindustry 逻辑？

Mindustry 逻辑 *(mlog)* 是 v6 中加入的一种脚本语言，目的是为游戏引入更高级的自动化和策略。它深受汇编语言启发，每次只能执行一条指令或操作。这与 Python、Java 或 C++ 等更流行的语言非常不同；那些语言提供了便捷的方式来创建单行语句、函数、条件语句、循环和类。

该语言目前的能力包括：

* 获取方块和单位的信息，包括玩家
* 控制建筑和炮塔
* 控制单位，并向单位写入/读取信息
* 在显示屏中显示形状和颜色
* 通过信息板输出文本
* 从内存元 / 内存库读取信息，以及向内存元 / 内存库写入信息
* 通过开关方块读取玩家输入
* 一元和二元数学运算
* 以及更多功能！
  
## 开始学习 Mindustry 逻辑前需要准备什么？

最好提前具备一些编程经验，至少了解相关概念和理论。这可以帮助你理解这门语言的一些技巧和概念。但最重要的是，你需要*耐心和开放的心态*，因为很多内容会在更新之间发生变化，而且许多东西在你亲自尝试之前可能显得令人生畏又复杂。

如果你不理解本文中使用的某些编程术语，可能也需要随时使用 Google 查询。

## 为什么 Discord 上 #logic 频道里大家都很粗鲁？

大多数时候只是因为你问题的答案触手可及，你需要做的只是安装本手册或更认真地阅读它。几乎总是如此：你只需要彻底 RTFM（阅读这本精彩的手册），就能找到答案。如果你完全确定这里没有涵盖你的问题，欢迎在 #logic 中提问。

如何提出有效的问题：

* 首先，尝试借助本手册或 **Google** 自行弄清楚。*说明你已经尝试过什么、已经知道什么。*
* 请__**不要**__发布极其常见的问题，例如“我要怎么控制炮塔”或“如何让单位移动”。再次强调，你可以在这里找到答案。
* 请__**详细**__提问，让任何帮助你的人都拥有有效解决问题所需的全部上下文。

我们会尽力不表现得粗鲁或无礼，但不符合这些标准的问题可能会考验我们的耐心，尤其是在解决方案很简单并且手册已经覆盖的情况下。__**向别人询问手册中已经清楚写明的问题，是在浪费别人的时间。**__

可接受的问题结构和态度示例：

* “我读完手册后，还是不明白 double 到底是什么。我不能直接用 int 吗？”
* “我在使用 radar 时遇到问题。即使我在炮塔范围内，它也检测不到我的玩家。这是我的代码：”
* “为什么我不能在同一条 print 指令中正确打印一个字符串和一个变量？”

并不是每个人都能一直做到这一点，所以至少请尽力把你的问题整理得像样一些，并至少遵循这些准则中的一条。
