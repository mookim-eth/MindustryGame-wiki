# 常见问题

## 如何和朋友/敌人一起玩多人游戏？

如果你们在同一个 Wi-Fi 或热点网络中，这应该很简单。开始一局游戏，打开暂停菜单，然后按下“创建联机游戏”按钮。这会让同一网络中的所有人都能加入你的游戏。要从另一台设备加入这局游戏，请点击“开始游戏 > 加入游戏”。如果是另一名玩家在托管，游戏应会出现在服务器列表中。

## 我找不到朋友的多人游戏！

如果你确定你们在同一个网络中，但仍然找不到对方的游戏，可以考虑使用 Wi-Fi 热点，而不是公共网络。有些公共 Wi-Fi 网络就是不允许发现服务器。

如果你使用的是 Wi-Fi 热点，但仍然找不到朋友的游戏，可以尝试通过 IP 直接连接。不要在列表中寻找游戏，而是找到托管设备的内网 IP（请查询如何在你使用的具体设备上找到它），然后让另一名玩家在“开始游戏 > 加入游戏 > 添加服务器”按钮中输入该 IP。

## 怎样和不在同一网络的人一起玩？

你需要设置端口转发，并把你的 IP 分享给其他玩家。请参阅[这里的指南。](https://mindustrygame.github.io/wiki/servers/)

可以考虑使用公共服务器，例如游戏内已有的那些服务器。

## 如何搭建专用服务器？/ 如何设置端口转发？

请参阅[这篇指南。](https://mindustrygame.github.io/wiki/servers/)

## PC 玩家可以和 iOS/Android 玩家一起玩吗？

可以，Mindustry 完全跨平台。只要所有设备运行的是同一版本的 Mindustry，任何设备都可以连接到任何其他设备。

## 如何导入地图？

首先，你需要确保地图与你的游戏版本兼容。如果你运行的是 Mindustry 4.0 或更高版本，你需要一个 .msav 地图文件。
把文件下载到设备后，打开 Mindustry 主菜单。选择“地图编辑器 -> 导入 -> 导入文件”（在屏幕顶部）。找到地图所在的目录，选择该文件并按“打开”。  

请注意，文件选择器只会显示扩展名为 .msav 的文件。如果找不到文件，请确认你查看的位置正确，且扩展名无误。请注意，Discord 有时会在下载文件时移除文件扩展名，因此你需要打开自己选择的文件浏览器，并手动添加扩展名。

## 如何导出地图文件？

在编辑器中打开你的地图。打开菜单，然后按“导出”。选择一个目录，输入文件名，然后按“保存”。

## 我因为某些原因不喜欢当前版本的 Mindustry，该怎么办？

只需下载 Mindustry Classic，即可获得旧版体验。它与 build 3.5 40 相同，不过包含一些小的错误修复。

PC/Android APK：[https://anuke.itch.io/mindustry-classic](https://anuke.itch.io/mindustry-classic)

你也可以在 Google Play 商店中搜索“mindustry classic”找到它。

## Mindustry 能在 Raspberry Pi 上运行吗？

虽然游戏本体理论上可以支持它，但不，游戏并不支持 Raspberry Pi。

不过，只要安装了正确版本的 Java，专用服务器就可以在 Pi 上运行。请注意，3.5/Classic 专用服务器无法在 Pi 上运行；仅支持 4.0 及以上版本。

## 如何加入 Google Play beta 计划？

打开 Mindustry 的 Google Play 页面，滚动到页面底部并点按“加入 beta”。点按按钮后，Beta 构建可能需要一些时间才会可用。请耐心等待。我无法控制这个过程有多快；它由 Google 自动处理。

## 我无法连接到服务器 / 我的游戏版本过旧。该怎么办？

如果你在 Android 上使用 Google Play，请等待更新可用。构建通常会在公告发布前完成更新，但 Google 可能需要数小时来处理。请耐心等待。  

如果你在 iOS 上，情况相同，只是可能需要等得更久一点。iOS 构建发布所需时间更长，而且 Apple 即使在上传后也需要 1-2 天来验证每个版本。

如果你使用桌面版，只需通过本页面顶部的链接前往 itch.io，并重新下载游戏。  

*更新不应重置进度。*

## 既然游戏可以免费获取，为什么 Steam 和 iOS 上还要收费？

游戏在 Steam 和 iOS 上收费，是因为这是支持 Anuke 的一种方式，并且这些版本拥有免费版本没有的功能，例如：

- 地图、模组和蓝图浏览器
- 使用 Steam Multiplayer 的安全、无缝多人游戏（无需端口转发）
- 启动时公开可见的服务器
- 成就
- 统计追踪
- 使用 Steam 进行云存档和进度转移
- Steam 社区

在 App Store 上分发游戏成本很高，因为开发者需要一台 Mac，以及每年 100 美元的开发者许可证。因此在该平台上为游戏收费可以覆盖这类开支。

## 我如何为游戏做贡献？ 

- 最简单的方式是在我们的 Discord 服务器中提供建设性反馈并参与讨论（最好是关于游戏本身）。
- 在 GitHub 仓库中报告你发现的错误。**请记得正确使用模板**，这样做会让你的 issue 更有条理，并遵循统一格式，从而让 Anuke 的工作更轻松。如果你懂 Java 编程，欢迎帮助 Anuke 修复这些错误，然后开启一个 PR。
- 如果你想做出金钱贡献，可以在 Itch.io 页面向 Anuke 捐款。你也可以在 Steam 上购买游戏。
- 如果你精通 Mindustry 尚未支持的语言，或者想为已有语言做贡献，请前往 #translations 频道并询问相关事宜。你可以为当前语言包做贡献，并在游戏仓库中开启 PR。
- 如果你想为这个 wiki 做贡献，请联系 Anuke 或 Luxray5474。他们会告诉你应该做什么，以及我们的协作方式。
