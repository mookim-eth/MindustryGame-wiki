# 服务器

服务器是 Mindustry 的重要组成部分，因为它们提供了与他人一起游玩的能力。服务器主要有两种类型：专用服务器和本地 LAN 服务器。

## 专用服务器

专用服务器是独立、无界面版本的游戏，只专注于为玩家提供多人游戏方式。它们通常作为独立程序在电脑上运行，而不是在游戏内运行，并通过终端操作。它们通常比本地 LAN 服务器更强，因为有更多资源可用于支持两三名以上玩家，并且可以 24/7 运行。它们也更加灵活和强大，因为有许多命令可为管理员提供更多控制，而且可以轻松安装模组，以符合管理员的需求。

你可以使用“开始游戏”菜单下的“加入游戏”按钮连接到专用服务器。与本地 LAN 服务器不同，你需要输入主机的 IP 地址和端口。也与本地 LAN 服务器不同的是，一旦你添加了服务器，它就会在你打开服务器列表时自动显示，游戏也会自动检查服务器状态。

要建立专用服务器，**强烈**建议使用专用的 Linux 或 Windows 机器。

1. 如果还没有安装 Java，请先安装。
2. 从 [itch.io](https://anuke.itch.io/mindustry) 或 [GitHub 发布版本](https://github.com/Anuken/Mindustry/releases) 下载所需的服务器版本。文件名应为 `server.jar` 或 `server-release.jar`，但如果你使用 Windows，它可能只显示为 `server` 或 `server-release`。
3. 将服务器文件移动到你想要的文件夹。建议把它放在桌面的新目录中。
4. 打开一个新的终端窗口（如果你使用 Windows，则打开 CMD）。使用 “[cd](https://www.digitalcitizen.life/command-prompt-how-use-basic-commands/)” 命令进入你放置服务器文件的目录，例如先运行 `cd Desktop`，再运行 `cd Server`。运行 `java -jar [server].jar`，将 \[server] 替换为你的服务器文件名。
5. 你的服务器应会启动。输入 `help` 查看所有控制台命令列表。如果你收到类似 “Unable to access file server.jar” 的消息，很可能是你所在目录不正确。
6. 使用 `host <mapname> [mode]` 命令开始托管地图。
7. 如果你使用 Windows 运行服务器，请用你常用的搜索引擎查询如何向 Windows 防火墙添加规则，因为它大多数时候会阻止必要端口。请确保允许 **6567 TCP 和 UDP 端口**。
8. 要关闭服务器，可以关闭终端窗口，或在终端窗口中按 Ctrl+C。

除非你已经启用了端口转发，否则只有本地网络内的客户端才能连接到你的专用服务器。如果你想让服务器在全球范围内可访问，请继续阅读下文。

### 什么是 IP，我如何知道自己的 IP？

简单来说，IP 地址是一个在互联网上标识你电脑的数字。如果你知道某人的 IP 地址，就可以连接到他的 Mindustry 服务器。地址分为两种：**公网**地址和**本地**地址。

- 对于**本地 IP**，例如你想和同一网络中的朋友一起玩时，每台设备都有自己的查看方式。你可以用 Google 查询适用于你设备的方法，例如“find local ip on Mac”。
- 对于**公网 IP**，你只需用 Google 搜索“what is my ip”。

### 在家运行专用服务器

大多数情况下，你应该记住这一点：**如果你是在家中托管服务器，除非你清楚这样做的影响，否则绝不要向公众分享你的公网 IP！** 你的公网 IP 与你的家庭网络相关，如果落入他人之手，可能使你的网络暴露在漏洞和危险中。**请谨慎行事，做好研究，并尽可能使用 VPN 或 Web 主机。**

还建议你为公共服务器使用域名或 DNS 服务来隐藏你的 IP，以便使用；更好的做法是使用云服务，例如 Amazon AWS，或使用 Linode、DigitalOcean 等托管提供商提供的专用服务器/VM，这样安全得多。**请做好研究**，并判断哪种选项最符合你的需求。

1. 找到你的路由器品牌/型号。这通常位于路由器底部或背面的贴纸上。
2. 使用你常用的搜索引擎搜索“port forward ASUS RT-ACRH17”，并按照指南转发 **6567 TCP 和 UDP 端口**。每种路由器的说明都不同，因此请务必仔细阅读你的指南！
3. 你可以使用 [You Get Signal](https://www.yougetsignal.com/tools/open-ports/) 等服务来检查端口转发是否正确完成。

## 本地 LAN 与 Steam 服务器

本地 LAN 或 Steam 服务器是内置于游戏中的服务器，可以使用游戏内菜单中的“创建联机游戏”按钮启动。它旨在简单直接，适合少数玩家在 LAN 网络（也就是你家中的 Wi-Fi 网络）中进行游戏会话。它并不真正适合大量玩家，因为这样使用会从你的设备占用越来越多资源；如果需要那样，请使用上文提到的专用服务器。它只能在游戏打开时运行，并会在游戏关闭时立即终止。

你可以使用“开始游戏”菜单下的“加入游戏”按钮连接到本地 LAN 或 Steam 服务器。与专用服务器不同，你的设备会自动找到主机设备，且它通常会出现在服务器列表中，而不需要你输入主机的 IP 地址。

## 专用服务器命令

$serverCommands

## 专用服务器配置选项
