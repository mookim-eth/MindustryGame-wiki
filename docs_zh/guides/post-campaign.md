# 通关后攻略：把战役玩成长期工程

> 目标读者：已经完成剧情模式关键终局目标的玩家。按当前源码，“通关弹窗”来自首次占领每个星球标记为 `isLastSector` 的区块：Serpulo 的行星发射终端，以及 Erekir 的起源。通关不等于当前存档无事可做。

## 1. 先确认：当前代码的“通关后内容”边界

不要把旧版本或传闻当当前源码内容。当前代码显示：

- Serpulo 与 Erekir 是实际可推进的主战役星球。
- Tantros 在代码中 `accessible = false`、`visible = false`，不能作为当前战役通关后的可玩星球目标。
- 若某些小行星在代码里存在，但 `accessible = false`，也不应被当作正常通关后攻略目标。
- Serpulo 仍有大量编号区块、敌基、隐藏提交区块、megabase 与可扩展后勤网络。
- Erekir 可做全关卡复盘、不同难度规则、自我限制与高效蓝图挑战。

## 2. 通关后的 6 类长期目标

| 目标 | 适合玩家 | 源码基础 |
|---|---|---|
| 全命名区块清图 | 想补完战役 | `SectorPresets` 定义了多个非主线/可选高难命名区块。 |
| Serpulo 编号区块征服 | 喜欢大战略 | Serpulo 允许编号区块发射与扇区入侵。 |
| 隐藏/社区提交区块挑战 | 想打高难敌基 | `SectorSubmissions.registerSectors()` 注册了多个隐藏 Serpulo 区块与 megabase。 |
| 全星球后勤网 | 喜欢自动化 | `Universe` 支持离线生产、发射/导入统计、区块库存。 |
| 高难规则重打 | 想挑战机制 | `Difficulty` 和战役规则会改变敌血、生成速度、波次时间。 |
| 蓝图/逻辑/速通优化 | 想追求效率 | 代码支持蓝图、逻辑处理器、单位控制、发射载荷等系统。 |

## 3. Serpulo 全图征服：先清“风险源”，再扩张

### 3.1 为什么清敌基比多占地更重要

`Universe.runTurn()` 会在 Serpulo 战役规则允许入侵时，根据已占领区块、是否有 spawns、邻近敌基数量与基础入侵概率触发入侵。被攻击区块会被冻结，生产、研究、发射物流都会受影响。

因此通关后扩张要按这个顺序：

1. 清理已占后勤区周边敌基；
2. 再占资源区；
3. 再建发射物流；
4. 最后挑战高威胁敌基/隐藏区块。

不要把一堆安全区块夹在敌基中间，否则它们会轮流被打断。

### 3.2 编号区块打法

Serpulo 编号区块可作为资源省、前哨、发射基地。注意：

- 向普通编号区块扩张需要邻近可发射来源；Serpulo 还额外要求发射来源最佳核心尺寸至少 4，也就是至少次代核心级别。
- 程序生成区块的胜利波次按威胁计算，不一定像命名区块那样固定。
- 如果编号区块生成敌基，要按攻坚图处理，而不是守波次。

推荐给每个编号区块一个标签：

- **矿区**：只负责基础矿和少量防御；
- **工厂区**：集中生产硅/塑钢/巨浪/相织物；
- **前线区**：存兵、存弹、接收后勤；
- **缓冲区**：占着减少敌基邻接，不一定重建大工厂。

## 4. 隐藏/社区提交区块：当前代码里是真内容

`SectorSubmissions.registerSectors()` 注册了大量 Serpulo 隐藏区块，其中很多默认 `requireUnlock = false`，若未设置 `captureWave` 就会把 sector 标记为生成敌基。代码里还把一批区块标为 megabase，并给某些区块设置更高难度/护盾关系。

**攻略建议**：

- 把隐藏区块当“后期敌基挑战”，不要用刚通关终局的临时经济硬打。
- 先用附近安全区块发射硅、钛、钍、塑钢、巨浪、相织物。
- 开局带大型核心和成熟蓝图，避免前 5 分钟资源断档。
- 建前线仓库和着陆台，持续导入弹药/建材。
- 用 T4/T5 单位或海军/空军绕开正面火力，优先拆敌电力、重构、修复、核心。

## 5. 全星球后勤网：把存档变成供应链游戏

### 5.1 设计原则

1. **单向物流清晰**：一个后勤区最好只向一个前线区或中转区发货。
2. **每种资源至少两个来源**：避免一个区块被入侵导致全前线停摆。
3. **前线只保留必要加工**：高耗时/高耗电生产放后方，前线接收成品。
4. **着陆台按物品分工**：一个着陆台配置一种资源，让导入速率和库存容易看。
5. **后勤区要能自卫**：离线生产不等于无敌；被攻击后统计会冻结。

### 5.2 推荐后勤资源优先级

| 级别 | 资源 | 用途 |
|---|---|---|
| S | 硅 | 单位、逻辑、炮塔、发射、几乎所有中后期内容。 |
| S | 钛 | 液体、塑钢、钻头、传送、核心和单位。 |
| A | 钍 | 核心、反应堆、相织物、高级墙与炮塔。 |
| A | 塑钢 | 传送、墙、重构、海军/空军与高级建筑。 |
| A | 巨浪合金 | 高级炮塔、墙、发射、终局科技。 |
| A | 相织物 | 高级墙、相位运输、终局单位/炮塔。 |
| B | 爆炸混合物/硫化物 | 弹药、发电、硅坩埚等支线消耗。 |
| B | 钢化玻璃 | 液体、海军、部分炮塔/建筑。 |

## 6. 通关后高难规则：理解 Difficulty 才能公平挑战

`Difficulty` 枚举不是只改 UI 名字：

- casual：敌人血量 0.5，生成 0.5，波次时间倍率 2；
- easy：血量 1，生成 0.75，波次时间倍率 1.5；
- normal：全 1；
- hard：血量 1.25，生成 1.5，波次时间倍率 0.8；
- eradication：血量 1.5，生成 2，波次时间倍率 0.6。

高难挑战建议：

- 先用 normal 建立可复用蓝图；
- hard 开始要求更早量产对空和水/冷冻冷却；
- eradication 不要贪扩张，先稳防线和电力；
- Erekir 高难下雾 + RTS AI + 敌方血量/生成倍率会放大侦察不足的惩罚。

## 7. 蓝图工程：通关后最值得优化的不是“最大”，而是“可复用”

### 7.1 Serpulo 蓝图库

- **3 分钟核心启动包**：核心旁铜/铅/煤/石墨/硅起步。
- **标准双路防线**：地面 + 对空 + 水冷接口。
- **高级发射基地**：发射台、油、电、输入缓冲、可改目的地。
- **着陆接收站**：多着陆台、分类入仓、核心/仓库溢流保护。
- **T3/T4 单位工厂**：单位工厂 + 重构 + 冷冻液 + 电力。
- **终局炮塔阵地**：厄兆/幽灵/熔毁/海啸等组合，带弹药和冷却。

### 7.2 Erekir 蓝图库

- **涡轮冷凝器电水站**；
- **铍/石墨/硅起步模块**；
- **电解机双输出模块**：氢/臭氧分离；
- **氧化物模块**；
- **热量短链模块**；
- **碳化物/氰气模块**；
- **装配厂 payload 模块**；
- **高热炮塔阵地**。

## 8. 自我挑战清单

通关后可以给自己设定源码支持的挑战：

- **全 Serpulo 区块占领**：含编号区块、隐藏敌基、megabase。
- **无暂停或更高难度战役规则**：源码的 `CampaignRules.pauseDisabled` 可影响暂停，难度规则可提高敌人强度。
- **最少区块通关路线**：只打必要科技门槛，测试路线规划。
- **无大型蓝图开局**：只用默认核心载荷，看临场建造能力。
- **Erekir 全关卡速推**：限制每关准备时间，练热量/单位链效率。
- **低核心等级挑战**：尽量不用最高级核心，检验小容量后勤能力。
- **只用某一单位线攻坚**：例如只用海军或只用机甲，测试地图理解。

## 9. 不要做的事

- 不要声称 Tantros 是当前通关后可玩内容；代码明确隐藏且不可访问。
- 不要把所有后勤都建在一个区块；入侵或失守会让全线断供。
- 不要在 Erekir 用 Serpulo 的长传送带思维；管道/热量/雾决定了更紧凑的布局。
- 不要只清主线区块就停用后勤；隐藏区块与高难重打会迅速消耗资源。
- 不要把发射台混装大量资源；后期排错会很痛苦。

## 10. 通关后最终目标：建立“可恢复系统”

真正稳定的通关后存档应该满足：

- 任一前线被打断时，有其它区块能补资源；
- 新区块落地 5 分钟内能形成矿线、电力、防线；
- 任一高级资源至少有可追踪来源；
- 能量、冷却、弹药、单位生产不会相互抢同一条细线；
- 有专门蓝图库应对 Serpulo、Erekir、攻坚、防守、海图、热量图。
