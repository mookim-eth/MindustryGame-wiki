# 新手攻略：从“能活下来”到“会自动化”

> 目标读者：刚开始 Mindustry 战役，或只会手挖/乱拉传送带的玩家。本文以当前源码为准，优先推荐从 Serpulo 的零号地区起步，再尝试 Erekir 的始发地区。

## 0. 新手先记住 5 条底层规则

1. **核心是仓库、出生点、败北条件**：战役里玩家核心全灭就 game over；核心容量限制你能存多少资源，也影响发射开局资源。
2. **传送带/管道/电线不是装饰，是生产线**：矿只要没进核心或没进工厂，就不算可持续经济。
3. **研究不只吃资源，还吃区块进度**：科技树节点常要求占领某区块、在某区块落地、或先产出某资源。
4. **波次图和攻坚图打法不同**：有 `captureWave` 的图区块守到指定波次；没有 `captureWave` 的命名区块通常要摧毁敌方核心。
5. **别让前线直接吃掉全部资源**：防线、弹药、电力、工厂都要有缓冲；核心库存不是越空越好。

## 1. 起步星球选择：为什么建议先 Serpulo

当前代码中 Serpulo 和 Erekir 都 `alwaysUnlocked`，但两者规则差异很大：

- **Serpulo**：允许波次、防守、编号区块扩张、发射资源和蓝图；适合学习传送带、钻头、炮塔和电力。
- **Erekir**：开局就有雾/静态雾，显示敌人出生点，玩家手动携带物品时受“只能存入核心”（`onlyDepositCore`）限制，也不能像 Serpulo 那样向编号区块随意发射；适合学会基础物流后再挑战。

**建议路线**：先打 Serpulo 零号地区 → 冰冻森林 → 陨坑战场 → 遗迹海岸/生物质合成区；期间可以试一试 Erekir 始发地区，但别把 Erekir 当纯新手教程。

## 2. Serpulo 前 30 分钟：搭出第一个稳定基地

### 2.1 零号地区：目标不是“打完”，而是“学会闭环”

源码里零号地区 `captureWave = 10`、`difficulty = 1`、`alwaysUnlocked = true`、`addStartingItems = true`。你的目标：

1. **铜矿 + 铅矿进核心**：每种矿至少 2–4 个机械钻头，传送带直连核心。
2. **双管炮塔先成线**：双管吃铜；用 2–4 个双管挡最初几波。
3. **不要让路由器贴路由器无限分流**：路由器会平均分到 3 个方向；早期更应该用直线传送带，只在炮塔前做分支。
4. **把防线建在敌人必经路，不要围核心一圈**：敌人没到核心前就应该被火力削掉。
5. **波次结束前攒资源研究**：优先研究传送带、交叉器、路由器、机械钻头、石墨压缩机、火力发电机/电力节点等基础链条。

### 2.2 早期资源优先级

| 优先级 | 资源/产物 | 为什么 |
|---|---|---|
| 1 | 铜、铅 | 传送带、基础炮塔、管道、电力节点和大量早期建筑都要用。 |
| 2 | 石墨 | 气动钻头、电力、液体、硅和中期炮塔会不断需要。源码中石墨压缩机把 2 煤变 1 石墨，生产时间 90 tick。 |
| 3 | 硅 | 单位、逻辑、许多中期建筑都需要。硅冶炼厂消耗煤 + 沙 + 电。 |
| 4 | 钛 | 钛传送带、气动/激光链、中期液体与核心升级关键。 |
| 5 | 钍、塑钢、巨浪、相织物 | 中后期资源，新手先知道名字，不要过早把基地复杂化。 |

## 3. 从冰冻森林到陨坑战场：学会电力和水强化

### 3.1 冰冻森林：电力入门

冰冻森林在源码中是难度 2、15 波。攻略目标：

- 建 **火力发电机**，烧煤发电。
- 用 **电力节点**连接石墨压缩机、硅冶炼厂、修理器等。
- 学会给防线留电力冗余：如果电力条忽高忽低，先加发电/电池，再加炮塔。
- 研究 **气动钻头**：它比机械钻头更适合中期矿线。

### 3.2 陨坑战场：水让很多建筑质变

陨坑战场难度 2、20 波；它是新手从“纯传送带”进入“液体系统”的关键点。

你要做的事：

1. **机械泵抽水**：用管道/液体路由器把水送到钻头或炮塔。
2. **水强化钻头**：源码里机械/气动/激光/爆破钻头都可用水或对应液体 boost；水能显著提高产量。
3. **水冷却炮塔**：分裂、蓝瑟等炮塔支持水/冷冻液加速。新手先会水，后面再学冷冻液。
4. **研究火成玻璃链**：窑炉把铅 + 沙变钢化玻璃；玻璃是液体建筑、海军和很多后续内容的基础。

## 4. 新手防线：不要只造一种炮塔

### 4.1 早期实用组合

| 威胁 | 推荐处理 | 说明 |
|---|---|---|
| 小型地面单位 | 双管 + 铜墙 | 最便宜，适合前几波。 |
| 空中单位 | 分裂 | 分裂只打空中，别拿它挡地面。 |
| 中型地面单位 | 电弧/火焰/蓝瑟 | 电弧和火焰处理群体；蓝瑟单发强但耗电。 |
| 多路线波次 | 每条路至少一小段独立火力 | 不要把全部炮塔堆在一条路。 |
| 后期厚血目标 | 波浪/海啸上状态 + 高伤炮塔 | 水/冷冻/熔渣等状态可辅助输出。 |

### 4.2 墙的正确用法

- 墙不是越厚越好，而是要让炮塔有射界。
- 传送带不要从墙前穿过；敌人打爆传送带会断弹药。
- 早期铜墙足够；有钛后用钛墙；后面按资源切换塑钢墙、钍墙、巨浪墙、相织布墙。
- 对空炮塔别被墙挡住弹道和视野；分裂放在后排即可。

## 5. 研究顺序：跟着源码科技门槛走

### 5.1 Serpulo 推荐研究线

1. **物流基础**：传送带 → 交叉器 → 路由器 → 分配器/分类器/溢流门。
2. **采矿与加工**：机械钻头 → 石墨压缩机 → 气动钻头 → 硅冶炼厂 → 窑炉。
3. **基础电力**：火力发电机 → 电力节点 → 电池 → 蒸汽发电机。
4. **基础防御**：双管 → 铜墙 → 分裂 → 冰雹/齐射/电弧/蓝瑟。
5. **单位入口**：地面工厂、空军工厂；攻坚图开始需要尖刀、爬虫、独影等单位。

### 5.2 什么时候去攻坚图？

如果区块没有 `captureWave`，通常意味着敌方基地图。新手去攻坚前至少准备：

- 稳定硅生产；
- 至少一种单位工厂；
- 足够电力与弹药；
- 进攻单位集结点；
- 用手控单位或指挥单位拆掉敌方外围电力/工厂，再打核心。

不要把 Salt Flats 这类攻坚图当“守波次图”；源码的胜利判断不鼓励你永远防守。

## 6. Erekir 新手入门：始发地区不是 Serpulo 翻版

Erekir 的始发地区 `onset` 难度 1 且总是解锁，但规则明显不同：

- **雾会限制视野**：先用雷达/推进前线，不要盲目把生产线拉到未知区域。
- **物品管道不是传送带**：Erekir 初期用 duct 系统；布局比 Serpulo 更强调方向与紧凑。
- **电力来自涡轮冷凝器 + vent**：不要把涡轮冷凝器随便放，它依赖地形属性。
- **铍、石墨、硅是早期核心链**：等离子钻机采墙矿/矿物，电弧硅炉吃石墨和沙产硅。
- **手动投放只进核心**：Erekir 规则里 `onlyDepositCore` 为真，别照搬 Serpulo 的“玩家随手往建筑塞物品”习惯；自动物流仍然要靠物品管道、桥和工厂接口完成。

## 7. 常见新手错误与修正

| 错误 | 后果 | 修正 |
|---|---|---|
| 手挖太久 | 资源增长停止，防线来不及升级 | 每种基础矿先放钻头，手挖只用于应急。 |
| 全图共用一根传送带 | 任何堵塞都会让全线停摆 | 弹药线、核心线、工厂线分开。 |
| 炮塔没有弹药缓冲 | 一波敌人打完弹药就断 | 炮塔前加小分支或容器，弹药线别太细。 |
| 只研究炮塔不研究电力 | 高级炮塔开不了火 | 每次加耗电炮塔前先看电网余量。 |
| 进攻图只防守 | 永远无法占领 | 造单位，拆敌核心。 |
| 过早打高难命名区块 | 资源与科技断档 | 按科技树门槛推进，先补硅/钛/玻璃/电力。 |

## 8. 新手阶段的阶段性毕业标准

你可以认为自己已经走出新手期，当你能做到：

- 自动生产铜、铅、石墨、硅、玻璃、钛；
- 能把水送到钻头/炮塔；
- 能分辨波次图和攻坚图；
- 能用单位摧毁一个敌方核心；
- 能在 3–5 分钟内从空核心搭起矿线、电力、基础防线；
- 能看懂科技树里“占领某区块/研究某物/产出某资源”的要求。

达成后，请继续阅读 [中级后攻略](midgame.md)。
