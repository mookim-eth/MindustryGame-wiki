# 中级后攻略：从“能过关”到“会经营一颗星球”

> 目标读者：已经完成若干源码 `SectorPreset.difficulty` 4–6 的区块，能生产硅/钛/玻璃，开始遇到大型敌基、多路线波次、海军、塑钢/钍/巨浪/相织物断档的玩家。

## 0. 本文如何定义“中级难度关卡”

源码里命名区块有 `difficulty` 字段，范围 0–10。本文把 **4–6** 视作中级：

- Serpulo 示例：风吹群岛、工业区 32M、边陲哨站、深险峡湾、盐碱荒滩、焦油田、边际海湾、萃取前哨、增生区等。
- Erekir 示例：岩浆湖、交错丘陵、风化山脉、芳油湿地、贫瘠峡谷、破碎火山、风蚀盆地、碳岩裂隙等。

进入这阶段后，游戏考验的不再是“会不会造炮塔”，而是：

1. 能否把资源链拉满；
2. 能否处理攻坚图；
3. 能否把安全区块变成后勤区；
4. 能否为后期核心/单位/炮塔提前准备材料。

## 1. 中级后的核心转变：从“地图内经济”转为“战役经济”

### 1.1 离线生产是战役经济基础

`Universe.runTurn()` 会在战役 turn 中把未受攻击、未游玩的区块生产统计加入库存；如果区块正在被攻击，会被冻结。也就是说：

- 安全区块可以持续当矿场/工厂；
- 前线区块不一定要自给所有高级资源；
- 被敌基邻近威胁的区块可能触发入侵，因此不能只建设不清边。

### 1.2 每个安全区块都应该有“职责”

| 区块类型 | 适合职责 | 目标产物 |
|---|---|---|
| 低威胁资源区 | 基础矿与硅 | 铜、铅、煤、石墨、硅 |
| 有水/沙区 | 液体与玻璃 | 水、钢化玻璃、冷冻液 |
| 有油/孢子区 | 化工 | 石油、煤、塑钢、爆炸混合物 |
| 有钍区 | 后期军工 | 钍、相织物、巨浪合金、钍反应堆燃料 |
| 海图/岛图 | 海军与塑钢支线 | 海军单位、塑钢、远程攻坚 |

**行动建议**：占领区块后不要立刻走。至少让它稳定把一种中高级资源输入核心，保存生产统计后再离开。

## 2. Serpulo 中后期路线：优先解决 4 个断档

### 2.1 第一断档：硅不够

中后期几乎所有关键内容都吃硅：单位工厂、重构、逻辑、发射、炮塔、核心升级。解决方案：

- 用多台硅冶炼厂并联，不要一条煤/沙线喂全图。
- 有煤有沙的区块专门做硅；没有煤时用孢子压榨石油，再用煤炭离心机从油产煤。
- 后期在热区用硅坩埚：源码中硅坩埚一次产 8 硅，但吃煤、沙、硫化物（`pyratite`）和更多电力；适合集中供电后使用。

### 2.2 第二断档：塑钢与油

风吹群岛后塑钢链变得重要。源码里塑钢压缩机消耗石油与钛，产塑钢；石油可来自孢子压榨或油井/油区。

建议：

1. 先在有孢子或油的区块建立油线；
2. 把钛送进塑钢压缩机；
3. 塑钢优先给塑钢传送带、塑钢墙、重构、后期单位与发射物流；
4. 不要把全部油拿去发电，塑钢优先级通常更高。

### 2.3 第三断档：钍、相织物、巨浪合金

- 钍需要更高钻头等级；激光钻头能采钍，爆破钻头更强。
- 相织物需要钍 + 沙 + 电；它是相织布墙、相位桥、重构与高级科技的重要材料。
- 巨浪合金需要铜、铅、钛、硅和电；后期墙、炮塔、发射与终局科技大量消耗。

**中期原则**：先把钍和硅稳定化，再开相织物与巨浪；否则你会造出几台工厂后把所有基础线拖垮。

### 2.4 第四断档：跨区发射物流

萃取前哨完成后，高级发射台研究路线打开；源码中高级发射台容量 100，发射时间 30 秒，需要油和 8f power，着陆台每次接收 100 物品并消耗大量水。

推荐做法：

- 每个后勤区只发 1–2 种资源，避免一个发射台混货导致目标区块难以接收。
- 目标区块用着陆台按物品配置，并把落地物品送进核心或本地缓冲仓。
- 导入前线的优先顺序：硅 > 钛 > 钍 > 塑钢 > 巨浪 > 相织物 > 爆炸混合物。
- 发射区被攻击时生产/物流会受影响，所以先清周边敌基。

## 3. Serpulo 区块推进建议

### 3.1 中级主线推进

1. **风吹群岛/遗迹海岸之后**：拿海军和塑钢线；补钛传送带、脉冲导管、蒸汽发电。
2. **盐碱荒滩/焦油田**：学会攻坚和油链；焦油田是油/煤/塑钢转型关键。
3. **边际海湾/海军要塞支线**：海军科技与后续高阶海军单位门槛。
4. **萃取前哨**：跨区物流关键；完成后开始用发射台经营前线。
5. **冲击区 0078/核裂阵/荒芜裂谷**：钍、反应堆、力墙、超速、高阶炮塔与终代核心准备。
6. **海滨船厂/行星发射终端**：终局海军与最终区块。

### 3.2 攻坚图通用模板

攻坚图不要无限守家。按源码，敌方基地图的胜利来自摧毁敌队核心。

**模板**：

1. 起手先做基础矿线 + 电力 + 防线；
2. 侦察敌核心方向；
3. 造单位工厂，先出 T1/T2 拆外围；
4. 用炮塔推进或单位集群打掉敌电力/修复/单位工厂；
5. 集中火力拆核心；
6. 占领后立刻修补核心、接资源、保存生产。

### 3.3 单位何时比炮塔更重要

- 敌核心在远处、隔墙、隔水时，炮塔够不到，必须出单位。
- 地形复杂时，用飞行单位或海军绕路；Serpulo 海军线在多个水图是关键。
- T3/T4/T5 单位贵，但能减少你在敌防线前铺一整条炮塔推进线的成本。

## 4. Serpulo 中后期防御：电力、冷却、状态组合

### 4.1 电力冗余

不要让电网刚好归零。中后期常见高耗电：蓝瑟、力墙、过载、差分发电/反应堆链、重构工厂、厄兆等。

实践标准：

- 关键防线旁边放电池，防止短时断电。
- 反应堆和冲击反应堆先在安全区测试，再复制到前线。
- 高耗炮塔最好独立电网或至少有备用发电。

### 4.2 冷却和状态

- 水/冷冻液提高许多炮塔射速。
- 波浪/海啸等液体炮塔可以上状态，帮助主输出炮塔。
- 对空必须独立考虑：分裂/旋风/厄兆等不能被地面火力替代。

## 5. Erekir 中后期：把“热量链”当成主线

Erekir 中级后从“铍 + 石墨 + 硅”进入“钨 + 氧化物 + 氢/臭氧 + 热量 + 碳化物”。

### 5.1 关键生产链

| 阶段 | 核心建筑 | 产物/作用 |
|---|---|---|
| 起步 | 涡轮冷凝器、等离子钻机、电弧硅炉 | 水、电、铍、石墨、硅 |
| 庇护前哨后 | 冲击钻头、通风冷凝器、强化管线 | 钨、水与更稳定物流 |
| 风化山脉/风蚀盆地 | 电解机、坦克重构厂、氧化室 | 氢、臭氧、氧化物、T2 单位 |
| 贫瘠峡谷/破碎火山 | 热导向器、电热器、炉类 | 热量、巨浪合金、碳化物前置 |
| 碳岩裂隙/平行岭谷后 | 碳化物坩埚、氰气合成器、装配厂 | 碳化物、氰气、T4/T5 单位 |
| 岩溶洞穴前后 | 相织物、魔灵、聚变/瘤变反应堆 | 终局防御与终局单位 |

### 5.2 Erekir 物流原则

- 物品管道和桥要短；长距离建议用 cargo 或 payload 体系。
- 热量链尽量短直，热生产贴近热消耗。
- 气体/液体分线：氢、臭氧、氮气、氰气用途不同，混乱会拖垮电解/合成。
- 雾中推进：先建雷达/防线，再扩张矿点。

### 5.3 Erekir 攻坚单位选择

- 坦克线：正面推进，适合拆坚固据点。
- 飞船线：跨地形，适合岩浆湖、水/坑阻隔地形。
- 机甲线：复杂地形适应性强，适合边打边拆。
- 装配单位：需要多个基础单位和墙块 payload，产能准备要提前 10–20 分钟规划。

## 6. 中级玩家蓝图标准化

到了中后期，你应该开始维护几类蓝图：

1. **核心起手包**：钻头、传送带/物品管道、电力、防线最小闭环。
2. **硅模块**：煤/沙输入，硅输出，带电力接口。
3. **石墨模块**：煤输入，石墨输出，可扩展多压缩机。
4. **冷冻液模块**：水 + 钛 + 电 → 冷冻液。
5. **塑钢模块**：油 + 钛 + 电 → 塑钢。
6. **巨浪/相织物模块**：高耗资源，最好只在安全区使用。
7. **Erekir 热量模块**：热源 + 热导向器 + 目标炉/炮塔的紧凑版。

蓝图不是为了偷懒，而是减少战役每个区块的启动时间，降低入侵/波次压力。

## 7. 中级阶段的检查清单

进入终局区块前，请确认：

- [ ] 至少一个安全区块稳定生产硅；
- [ ] 至少一个安全区块稳定生产塑钢；
- [ ] 有钍与冷冻液生产；
- [ ] 巨浪合金和相织物不是“手搓几百个”；
- [ ] 有高级发射台/着陆台物流或等效前线补给；
- [ ] 能生产 T3 以上单位，至少一种路线可量产；
- [ ] 会处理空军威胁；
- [ ] 电网有电池和冗余发电；
- [ ] Erekir 已经理解氢/臭氧/氧化物/热量链；
- [ ] 不把受攻击区块当安全后勤区。

## 8. 何时进入终局

Serpulo 终局前，你应至少能：

- 用终代核心或大型核心载荷开局；
- 量产 T4 级别单位，必要时冲 T5；
- 建立高阶对空与地面混合防线；
- 前线能持续导入硅/钛/钍/塑钢/巨浪/相织物。

Erekir 终局前，你应至少能：

- 建堡垒核心或卫城核心；
- 稳定生产碳化物、氧化物、相织物、氰气；
- 使用装配厂制造高阶单位；
- 为魔灵/高热炮塔提供热量与电力。
