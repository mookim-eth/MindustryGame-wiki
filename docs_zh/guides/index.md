# 攻略

这里收录基于当前 Mindustry 源码与本 Wiki 生成数据整理的中文攻略。若攻略文字与源码/自动生成的方块、物品、单位页面冲突，以源码和自动生成数据为准。

## 阅读顺序

1. [机制总览](mechanics-overview.md)：先理解战役、区块、科技树、资源、物流、电力、液体、热量、单位等底层机制。
2. [新手攻略](beginner.md)：适合刚开始战役的玩家，从 Serpulo 零号地区与 Erekir 始发地区入门。
3. [中级后攻略](midgame.md)：适合已经完成若干中级难度区块的玩家，重点是跨区物流、资源断档、攻坚和 Erekir 热量链。
4. [通关后攻略](post-campaign.md)：适合已经完成剧情模式关键终局目标的玩家，继续做全图征服、隐藏区块、后勤网、高难挑战和蓝图工程。

## 说明

- “中级难度”按源码 `SectorPreset.difficulty` 的 4–6 区间定义。
- 本攻略会引用源码路径（如 `core/src/mindustry/content/Planets.java`）作为依据，方便维护者复核。
- 本 Wiki 的建筑、物品、液体、单位等数值页由生成器产生；攻略不重复所有数值，只强调路线与决策。
